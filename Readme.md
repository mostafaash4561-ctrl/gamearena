# GameArena

A responsive gaming community landing page built with HTML, CSS and Bootstrap 5.
Responsiveness is handled by the Bootstrap grid and utility classes, with no custom media queries and no custom JavaScript.
The games slider and mobile menu use Bootstrap's built-in components.

## Sections

- Navbar and hero
- Latest games carousel
- What we do and moving partner logos
- Team members
- Contact info and form
- Footer

## Project Structure

```
├── Images/
├── JS/
│   └── bootstrap.bundle.min.js
├── Styles/

│   ├── bootstrap.min.css

├── index.html
└── Readme.md
```

## Getting Started

Open `index.html` in any modern browser.

## Note

This is a front-end practice project. The contact form has no backend.
